# Codex Agent 执行契约

本文件只定义平台映射。业务流程以调用入口链接的 `agents/<name>/AGENT.md` 为唯一事实源。

## 定位资源与项目

- 入口中的相对链接以该 `SKILL.md` 所在目录为基准。本文件所在目录 `codex/` 的父目录（`../`）是已安装插件根目录，Agent 与共享 Skill 从此根目录解析，不依赖用户项目中存在同名文件。
- 工作目录始终是用户当前项目。业务代码、状态文件、设计文档和命令在用户项目内操作，不写入插件安装目录，也不为读取插件资源切换项目目录。
- 执行业务前读取目标项目的 `AGENTS.md` 及当前平台适用指令。插件仓库的开发规则不能替代目标项目规则。
- 非 Codex 宿主误选此入口时，使用当前平台已注册的对应 Agent；若未注册，说明此入口面向 Codex，不改动其他平台配置。

## 读取与权限

完整读取 Agent 源文件后，将 YAML frontmatter 与正文分开解释：

- `name` 和 `description` 用于识别工作流；描述中的自动委派提示不代表新增授权。
- `tools`、`model`、`permissionMode` 是 Claude 平台配置，不转换为 Codex 的权限或模型设置。
- 保留正文中的阶段门禁、用户确认、状态恢复、验证和安全要求，遵循当前宿主及用户已明确的授权范围。
- `code-review` 保持只读：分析并报告，不编辑业务文件，不因忽略权限 frontmatter 而获得写权限。提示词约束不等于宿主沙箱，实际能力仍由 Codex 控制。
- 资源缺失或 frontmatter 损坏时报告具体插件相对路径，停止该工作流；不从其他仓库猜测替代正文。

## 能力映射

| 源 Agent 语义 | Codex 行为 |
| --- | --- |
| Read / Glob / Grep | 使用当前宿主的文件读取与搜索能力 |
| Write / Edit | 使用当前宿主的文件编辑能力 |
| Bash | 使用当前环境 shell，遵循目标项目的操作系统约定 |
| Skill / `Skill(skill: "name")` | 加载插件根目录 `skills/name/SKILL.md` 及其所需引用，或使用宿主已发现的同名技能 |
| `my-ext:kb-loader` 等命名空间 | 解释为本插件的对应技能；不把 Claude 冒号语法当作 Codex 命令 |
| Agent / Task | 按下方委派规则执行对应 Agent 正文 |
| AskUserQuestion | 使用当前宿主询问能力；不可用时用普通文本提问 |
| TodoWrite | 使用当前任务计划能力；不可用时以简短清单跟踪 |
| `.claude/worktrees/` | 使用用户已指定工作区或宿主隔离能力；需原生 Git worktree 时遵循项目约定，避免覆盖已有目录 |

源文中的外部技能必须已安装或可从当前宿主加载；缺失时说明能力缺口，不能假称已经调用。知识库通过本插件 `skills/kb-loader/SKILL.md` 解析，外部文档访问仍须满足当前宿主权限。

## 委派与工作流衔接

- 顶层调用在宿主支持且允许委派时，可把边界明确的任务交给子代理；传递本契约、Agent 源文件绝对位置、目标项目工作目录、任务目标、相关设计/计划和已有阶段状态。
- 已受委派的子代理直接执行正文，禁止因 frontmatter 的自动委派措辞递归创建同角色子代理。
- 正文引用另一个 Agent 时，从插件根目录 `agents/<name>/AGENT.md` 加载。共享 Skill 与 Agent 同名时按源文语义区分，例如 `fix` Skill 是 `skills/fix/SKILL.md`，`fix` Agent 是 `agents/fix/AGENT.md`。
- 缺少协作能力时，在当前代理内联执行相同工作流，仍保留阶段和确认要求。独立审查无法获得独立上下文时，明确报告为内联审查；若用户要求必须独立审查，则报告阻碍，不冒称已完成。
- `feature-dev` 的审查环节使用 `code-review` Agent 正文，保留只读职责；后续修复由开发工作流执行。

## 扩展开发的特殊映射

`cc-ext-dev` 源文件面向 Claude Code。用于 Codex 扩展任务时，复用其需求探查、内容组织、安全和验证流程，但所有平台示例表、清单路径、安装命令、Hook、MCP、权限及模型字段都只能视为 Claude 示例。

先查阅目标平台当前官方文档，再选择 Codex 支持的格式；不得将 Claude 专属配置直接写入 Codex。若用户实际请求 Claude 扩展开发，按该目标平台规则处理。
