# 设计文档骨架模板

提供本插件标准的设计文档骨架模板，供 `superpowers-planner` 等代理编写 Spec/Plan 时使用。模板文件通过本 skill 的目录解析加载（相对路径解析到本 skill 目录）。

## 文档分工（MUST）

- **Spec（设计规范）面向人审**，**Plan（实施计划）面向 agent 执行**：两份**独立成文、不混写**。
- 两类文档头部均维护「版本历史」表：任何实质修订（含临时调整）必须**追加一行**并**递增版本号**，不得覆盖旧行。

## 模板文件（必须读取模板内容）

- **Spec 骨架**：`templates/spec-skeleton.md` —— 设计规范必须章节（结论先行摘要 / 需求分析(为什么改) / 方案选择 / 架构与设计(怎么改，含就地伪代码/SQL) / 接口与 API / 数据模型 / 风险与待拍板 / 测试与验收；12 章 + 文档头 + 版本历史），**审阅导向**
- **Plan 模板**：`templates/plan-skeleton.md` —— 实施计划文档头(含版本历史) / 硬性约束 / 文件结构映射 / 任务粒度 / 执行波次 / 范围外禁止，**执行导向**

## 用法

1. 读取上述模板文件
2. 按骨架输出完整章节；某章节不适用时显式说明"不适用/无需"，不得省略整个骨架
3. 每次实质修订须同步在文档头「版本历史」追加一行并递增版本号
